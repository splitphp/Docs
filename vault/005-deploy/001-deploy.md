# Deploy In Production

_Put it out to the world!_

 As it was pointed out in the [[004-running|Running Application]] section of this documentation, one should, instead of using the PHP's _built-in_ web server to deploy applications on production environments, use a web server application as _Nginx_ or _Apache 2_. Here it is explained how to deploy your SPLIT PHP app using these two, which are the main solutions fot this in the current marketplace.
